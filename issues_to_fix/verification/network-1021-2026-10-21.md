## 自动测试与构建

```sh
./gradlew :mod-forge:test :mod-neoforge:test :cli:test assembleMods :cli:distZip
```

执行环境使用 Java 21 工具链、Forge 代码 release 17、NeoForge release 21；额外提供 JDK 17。最终常规校验未关闭 Gradle 依赖验证，新增 FTB 依赖的 SHA-256 已登记。

| 对象 | 结果 |
| --- | --- |
| Forge 1.20.1 / 47.4.10 | 47 项通过，无失败 |
| NeoForge 1.21.1 / 21.1.262 | 47 项通过，无失败 |
| CLI | 43 项通过，1 项跳过；跳过项需额外 Java 8 环境 |
| 两版 mod、CLI 分发包 | 构建成功 |

新增检查包括：

- 无 FTB/未认领分支不会调用荒野拒绝逻辑；已认领的交互/编辑四种组合、未就绪与跨维度拒绝。
- 同玩家不同 MCP、不同玩家、不同电脑、重复电脑 ID 的互斥；冒用 session、错误实例、旧 lease ID/epoch 均拒绝。
- 会话数量上限、open 重试键、重复 acquire 幂等、退出/断线/撤销/世界关闭清理、心跳不续业务空闲时间。
- 真实回环 HTTP 的本机令牌、路由白名单、空请求体、会话/租约凭据转发。
- 两个 `LiveTools` 实例的会话隔离、占用返回、释放后交接、正常退出关闭、心跳失败丢弃旧凭据、远程发现 URL 拒绝。
- 应用协议升级为 2，不兼容旧协议握手；保留原分块、连接 epoch 及断线检查。

以上多数使用纯状态模型或内存游戏传输；真实回环 HTTP 也使用游戏/服务器替身，不代表实际玩家数据包联调。

## 专用服务器启动

依次运行两版原生开发服务器，不安装 FTB 和带 `-PftbIntegration` 各一次。测试世界仅绑定回环地址，使用离线模式；`http.enabled=false`，网络桥启用。开发集成依赖不打包进发布 jar。

| 加载器 | FTB 组合 | 启动与诊断 | 结束 |
| --- | --- | --- | --- |
| Forge | 无 Chunks | 选择无领地全员可授权策略 | `stop` 保存完成，退出 0 |
| NeoForge | 无 Chunks | 选择无领地全员可授权策略 | `stop` 保存完成，退出 0 |
| Forge | Chunks 2001.3.8 / Library 2001.2.9 / Teams 2001.3.1 / Architectury 9.1.12 | `/cctlive network policy` 返回 FTB 管理器 ready | `stop` 保存完成，退出 0 |
| NeoForge | Chunks 2101.1.22 / Library 2101.1.34 / Teams 2101.1.9 / Architectury 13.0.8 | `/cctlive network policy` 返回 FTB 管理器 ready | `stop` 保存完成，退出 0 |

四组 CC:T terminal/wired_query 能力均可用，未创建服务端 HTTP endpoint，没有专用服务器误加载客户端类的问题。通过测试用本机 RCON 执行诊断与 `stop`；RCON 只是测试启动配置，不是 mod 的网络桥要求，不应为使用 mod 开启公网 RCON。

Forge 首次集成启动发现 LegacyForge 的 modRuntimeOnly 没有自动带入 FTB 的必需 mod，已显式补充 Library、Teams、Architectury 后重验成功。启动器进程退出 0 本身不足以证明游戏启动，以上同时检查 `Done`、实际策略输出和保存记录。初次信号终止记录不作为最终干净退出证据。

[启动结果](../evidence/dynamic/results-1021/server-startup.json) · [实际日志节选](../evidence/dynamic/results-1021/server-startup-excerpt.txt)

可重复启动命令：

```sh
./gradlew :mod-forge:runServer
./gradlew :mod-neoforge:runServer
./gradlew :mod-forge:runServer -PftbIntegration
./gradlew :mod-neoforge:runServer -PftbIntegration
```

按 Minecraft/加载器要求准备本机测试目录、同意 EULA、关闭服务端 HTTP；启动后执行 `cctlive network policy` 和 `stop`。安装 FTB 后的管理器 ready 只证明可选依赖加载和 API 可用，不能证明实际领地权限判定正确。

## 尚未验收或实现

没有图形客户端和真实玩家联调，以下仍待双版本验收：授权按钮往返、非 OP 的荒野命令授权、FTB 四种交互/编辑组合、团队/盟友/绕过变化、同时抢锁、动态失权、移动电脑和原生界面并存。

跨维度已认领目标适配、口袋电脑、旁观会话、管理员强制交接、异步任务去重/取消/收束，以及写文件冲突与可靠提交仍未实现。当前锁只协调同步 MCP 数据读取，不保证电脑程序、玩家操作或外设活动互斥。因此 NET 项保持 open，不把 97 项历史问题的状态统计改成已完成。
