# cct-run 0.3.0

0.3.0 为 cct-live 新增 **Minecraft 网络桥预览**：多人服务器上的玩家可以通过已有的游戏连接，让自己电脑上的 AI 只读查看自己授权的 CC:T 电脑。服务器不需要开放额外端口。同时接入 FTB Chunks 领地权限，并让多个 MCP 会话互斥使用同一台电脑。**cct-run、客户端 mod 与服务端 mod 需要一起升级**（网络应用协议 3）。

## 下载与要求

| 文件 | 用途与要求 |
|---|---|
| `cct-run-0.3.0.zip` | 命令行工具、本地 stdio MCP 服务器、文档与测试脚本；运行需要 Java 17+ |
| `cct-live-1.20.1-0.3.0.jar` | Minecraft 1.20.1、Forge 47.x、Java 17+、CC: Tweaked **1.120.2** |
| `cct-live-1.21.1-0.3.0.jar` | Minecraft 1.21.1、NeoForge 21.1.x、Java 21+、CC: Tweaked **1.120.2** |
| `verification.json` | 本次发行 CI 的四模块 JUnit 执行结果，含源码提交与验证状态 |
| `SHA256SUMS` | 上述 zip、两个 jar 和验证报告的 SHA-256 校验值 |

两个 mod 共享实现，选择与游戏加载器匹配的一个，不要同时安装。使用网络桥时**客户端和服务端都要安装**同一版本；单人游戏和原有管理员本机 HTTP 模式的安装方式不变。CC: Tweaked 仍固定 1.120.2。FTB Chunks 是可选依赖，不随 mod 打包，也不要求客户端安装。

## 网络桥（预览）

- **连接方式**：客户端 mod 在 `127.0.0.1` 随机端口提供带令牌的本机桥，发现文件在 `<游戏目录>/cct-live/client/`；请求经游戏连接转发到服务端。远程服务器不增加 HTTP/MCP 端口。
- **只读范围**：只提供授权电脑列表、状态与当前屏幕（含直接连接的显示器）。文件、Lua、输入、开关机、快照、trace、外设查询及原有 attach/detach 在网络桥上均不可用。
- **授权**：打开电脑或海龟界面，点击界面左侧外、与终端屏幕上缘齐平的 **AI** 图标（白色=未授权，绿色=已授权，点击切换）；或在电脑旁使用 `/cctlive network authorize <ID>`。另有 `revoke`、`list`、`policy` 子命令。授权固定 30 分钟，可随时撤销。手持平板电脑暂不支持。
- **FTB Chunks**：已认领区需要有效的方块交互**且**编辑许可；未认领区（包括启用 `no_wilderness` 时）和未安装 FTB 时，所有非旁观玩家都可授权。FTB 未就绪或查询失败时拒绝访问，不会放行。显示器按其所在区块单独检查。已认领电脑暂要求玩家与其处于同一维度。
- **MCP 独占会话**：每个 MCP 连接都有独立会话，同一玩家的不同连接也互斥。先用新工具 `cct_live_control {computer, op:"acquire"}` 获取租约，再读取状态/屏幕，用完 `op:"release"`。心跳自动进行；默认租约 60 秒、空闲 300 秒释放（`network.lease_seconds`、`network.idle_seconds`）。不拦截原生 CC:T 界面。
- **单人世界**：玩家自己的集成服务器（单人或局域网主机）不启动客户端桥，继续使用原有全功能的管理员本机端点。一个 MCP 连接用过网络桥后，断线不会自动切换到管理员端点。

详细说明见 [网络桥使用说明](https://github.com/EvergardenRoxy/CC-Tweaked_MCP/blob/v0.3.0/docs/development/network-preview.md)。

## 配置

服务端 `config/cctlive-common.toml` 新增 `[network]`：`enabled`（默认 true）、`lease_seconds`（30～300，默认 60）、`idle_seconds`（300～86400，默认 300）。网络桥与 `[http]` 互相独立，关闭服务端 HTTP 不影响网络桥。

## 升级时需要注意

- 网络桥的客户端、服务端与 cct-run 必须同为 0.3.0；协议不匹配时握手失败并提示，不会降级。
- 原有管理员本机 HTTP 模式、模拟器和其他 MCP 工具的用法不变。

升级步骤：替换 cct-run 解压目录，把游戏 `mods/` 中旧 cct-live 替换为对应的 0.3.0 jar（多人服务器的服务端与每个使用网络桥的客户端都要替换），然后重启游戏与 MCP 客户端。

## 验证范围与已知限制

发行前本地 Linux 回归：engine 55、cli 45（2 项因环境跳过：无 Java 8、非 UTF-8 locale）、Forge 53、NeoForge 53，全部通过；严格依赖校验构建、发布脚本测试通过；实际安装包冒烟 20 项通过、1 项跳过（Java 8 启动器切换）。最终以发行 CI 的 `verification.json` 为准。两个专用开发服务器在有/无 FTB Chunks 时均启动成功并输出正确的授权策略。

**尚未进行真实客户端与多玩家联调**：AI 图标显示与点击、FTB 各种权限组合、显示器跨领地拒绝、同时抢锁、断线重连等仍待实机验收。网络写入、文件、异步任务、跨维度已认领目标、平板电脑和管理员强制交接尚未实现，对应 NET 待办保持 open。本轮未测试 Windows、macOS 或生产服务器。详见 [1021 验证记录](https://github.com/EvergardenRoxy/CC-Tweaked_MCP/blob/v0.3.0/issues_to_fix/verification/network-1021-2026-10-21.md)。
