# 模拟范围与已知限制

[← 返回 README](../../README.md) · [用法](usage.md) · [测试记录](../testing/results.md)

模拟测试通过，表示程序在下述模型中运行正确。依赖真实世界或其他模组行为的程序，仍需在玩家授权后用 cct-live 验证。

| 范围 | 当前行为与游戏的差异 |
|---|---|
| 电脑与世界 | 只有普通/高级电脑；没有海龟、口袋电脑、命令电脑、方块世界、区块加载或服务器卡顿。每次运行一个独立 JVM，按真实时间约 20 tick/s 推进。 |
| 容器 | 每格接受任意物品、上限 64，详情字段有限；不模拟熔炉、模组机器的格子规则。转移按 Forge 的目标格子顺序进行。 |
| 流体与能量 | 提供 fixture 中的值，只随时间线改变；流体只提供 `tanks()`，不模拟流体转移或机器联动。 |
| scripted 外设 | 方法返回 fixture 指定的值，`sets` 和时间线可以改变它；不模拟机器之间的因果关系。数值与事件格式应取自实机。 |
| 网络与事件 | 有线网络成员固定；发送 modem 消息会记录，但没有其他电脑回复。不提供无线/末影网络、HTTP、WebSocket、扬声器、打印机和磁盘驱动器。 |
| 显示器 | 尺寸取自 fixture，触摸需注入事件；模拟 trace 只记录文字，不记录颜色。游戏字符集无法直接显示中文。 |
| 时间与 shell | 游戏内 `os.time()` / `os.day()` 固定为 0；默认关闭 multishell，`startup.lua` 由测试 harness 占用。 |
| 磁盘 | 根盘容量 1,000,000 字节，按上游 `WritableFileMount` 每项至少 500 字节计费，目录、预置文件、程序和 harness 均占用；增长、追加、seek 后写入均受限。删除或截断可释放空间。摘要 `disk` 区分占用与累计写入。模拟器删除文件时会关闭该路径的打开句柄，避免已删除的内存文件逃过配额；宿主文件系统对删除后句柄的处理可能不同。 |
| 内存与结果 | 整个 JVM 默认约 1 GB 堆；游戏电脑共用服务器堆，没有单台电脑上限。`out_of_memory` 依据观察到的 Java OOM 类型判定，即使 Lua 接住该错误也会标记；普通 Lua 错误包含相同文案不会被当成 OOM。固定 CC:T/Cobalt 版本的适配器不可用时会明确失败。完整 debug 权限仍可影响被测程序本身，harness 加固不构成恶意代码隔离。 |
| 输入 | MCP 单行及 fixture 文件最多 16 MiB（字节），JSON 容器深度最多 128、节点最多 100,000；超大 MCP 行有界丢弃后继续处理下一行。超时 1–3600 秒。 |
| trace 数据 | 参数/返回值是有界预览：嵌套最多 4 层、每容器最多 50 项、字符串默认 200 字符。数值按 Lua double 表示，大整数可能失去精度，非有限值以字符串表示。输入边界与预览截断彼此独立。模拟器 trace 尚无磁盘大小上限；长时间运行应自行管理输出目录。 |

摘要的 `notes` 只保留最先出现的 10 条值得注意的记录；超出的条数在非零时以 `notes_dropped` 给出。对应记录仍写入 `trace.jsonl`，需要完整诊断序列时查询 trace；参数和返回值仍受上表的预览限制。

异常退出时先看运行目录的 `state.json`。`starting` / `running` 只是最后已知状态；外部 SIGKILL、断电可能来不及写 summary 或终态，不能把残留状态当成进程仍存活。可结合 `pid`、`pid_started_at` 核对。MCP 自己取消或强杀子进程时会更新对应目录，正常结束会写 `finished`。

cct-live 是原型。它按接管/租约控制权限；区块卸载报告“未加载或不可用”，重新加载不会自动恢复 AI 接管。文件写入默认关闭。trace 只保留配置额度内的两个段；更早数据不再可查，`first_seq` 表明保留窗口，`trace_health` 显示丢弃与写入故障。普通分页查询的 `matched_at_least: true` 表示 `matched` 只是下界，精确数量请用 summary 查询。screen hash 包括尺寸、文字和前景/背景色，值仅用于比较变化。

本轮 Linux 自动测试与开发服务器覆盖范围见[验证证据](https://github.com/EvergardenRoxy/CC-Tweaked_MCP/blob/1019fix/issues_to_fix/evidence/dynamic/results-1019fix/README.md)。macOS 尚未验证；本轮未重跑 Windows 客户端及生产服务器。历史环境的通过记录不代表当前构建已在所有平台验证。
